First development release of Uclient, a desktop client for kinematics, dynamics and 3D visualization of UFACTORY arms, built on [ufactory_genesis](https://github.com/xArm-Developer/ufactory_genesis) and Pinocchio.

## Features
- Pose + payload torque check: enter a TCP pose (mm/°, Studio conventions), get all IK solutions and static gravity torque per joint, split into arm and payload, with % of rated torque.
- TCP Offset and TCP Payload defined as in UFACTORY Studio (total mass, COM relative to the flange).
- Joint sliders with live FK and torques, IK solution picker, CSV export.
- 3D viewport (three.js) rendering the robot URDF/GLB models with TCP axes and payload COM marker.
- Chinese / English interface.

## Supported models
UF850, xArm5 / xArm6 / xArm7 (`_1305` revision only), Lite6.

## Platform
Linux x86_64, **deb package only** (tested on Ubuntu 22.04+). Windows and macOS are not packaged.

## Install
```bash
sudo apt install ./Uclient_0.1.0_amd64.deb
uclient
```
Verify the download with `sha256sum -c SHA256SUMS.txt`. The package is **unsigned**.

## Known issues
- The installer is large (~100 MB) because the bundled Pinocchio engine pulls in extra libraries (coal, assimp, OpenBLAS); size reduction is planned.
- Windows is not packaged yet (planned for milestone M5).
- Rated torques come from ufactory_genesis commit `60fe926` (development values); percentages will change once official ratings are published. Absolute torques are unaffected.
- Results are static models: nominal URDF inertia, no friction, gearbox efficiency or per-unit calibration.
