UGClient (UFACTORY Genesis Client) is a desktop client for kinematics, dynamics and 3D visualization of UFACTORY arms, built on [ufactory_genesis](https://github.com/xArm-Developer/ufactory_genesis) and Pinocchio.

## Compact motion bar and floating STOP
- The motion bar is smaller (240 px tall, 140 px XYZ/RPY jog pads), which leaves more room for the 3D view.
- **STOP** is now a floating red button at the top right of the 3D view, level with the view toolbar. It still stops all motion and sets the simulated state to 4.
- The **中/EN** language switch sits next to STOP.

## RGB coordinate axes
Base and TCP axes are drawn as solid **X red / Y green / Z blue** lines, always visible over the robot. The view toolbar shows a matching X Y Z legend.

## Home and Align: click or hold
Home and Align now work like the jog buttons:
- **Click:** one joint-space step toward the target (at most the angular click step per joint), then state 4.
- **Hold:** continuous motion at joint speed until you release (state 4) or the target is reached.
- If the Align pose can't be reached, the error appears before anything moves.

Jogging is still **simulation only**. Nothing connects to a real robot.

## Settings
The ⚙ **Settings** button at the bottom of the left panel opens a dialog with four sections. Settings are saved locally.
- **Jog:** click step for linear axes (mm, default 1) and for angular axes and joints (°, default 1). Linear steps are limited to 0.01-100 mm and angular steps to 0.01-45°. The 300 ms hold threshold and the speed scale (230 mm/s, 40 °/s at 100 %) are fixed for now.
- **Safety boundary, saved per robot model:**
  - TCP X/Y/Z min and max in the base frame. Leave a field empty for no limit.
  - Joint min and max for each joint. These default to the model's joint limits and can't be set outside them.
  - Jog, Home and Align stop at the boundary, and a message names the axis, e.g. "TCP Z reached the safety boundary (max 240.0 mm)". Moving back inside the boundary is allowed.
- **General:** language (synced with the top-right switch), default robot model, and an option to restore the last session (robot, end effector, TCP offset, payload, joint angles) at startup.
- **About:** app, engine, ufactory_genesis and Pinocchio versions, MIT license, personal-project note.

## Install / upgrade
```bash
sudo apt install ./ugclient_0.3.0_amd64.deb
ugclient
```

## Supported models
UF850, xArm5 / xArm6 / xArm7 (`_1305` revision only), Lite6.

## Platform and install
Linux x86_64, deb only (tested on Ubuntu 22.04+). Verify with `sha256sum -c SHA256SUMS.txt`. The package is **unsigned**.

## Known issues
- Jogging is simulation only.
- When you hold a button, motion can stop a few mm or degrees before a safety boundary instead of exactly on it.
- The joint torque table and the target-pose IK form still have no UI. The engine API (`dyn.gravity`, `check.pose`, `kin.ik`) is unchanged.
- The installer is large (~100 MB) because of the bundled Pinocchio engine.
- Windows is not packaged yet; macOS is not supported. The package is not signed.
