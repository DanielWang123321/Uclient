> **UGClient is a personal project in development. It is not an official UFACTORY product and is not affiliated with or endorsed by UFACTORY.**

UGClient (UFACTORY Genesis Client) is a desktop client for kinematics, dynamics and 3D visualization of UFACTORY arms, built on [ufactory_genesis](https://github.com/xArm-Developer/ufactory_genesis) and Pinocchio.

## Renamed: Uclient -> UGClient
- Product name **UGClient** (formerly *Uclient*); repository `DanielWang123321/ugclient` (old URLs redirect).
- The deb package and command are now **`ugclient`** (was `uclient`); the bundled engine is `ugclient-core`.
- Project files are now `*.ugclient.json`; **old Uclient project files (`*.uclient.json`) still load**.

### Upgrading from 0.1.0
The package name changed, so remove the old package first:
```bash
sudo apt remove uclient
sudo apt install ./ugclient_0.1.1_amd64.deb
ugclient
```

## Fixed: end effectors could not be added
Gripper G2, BIO Gripper G2, Lite6 gripper and Lite6 vacuum gripper could not be selected/shown because their 3D meshes were not bundled. They now mount on the flange in 3D. Selecting an end effector sets its default TCP offset (still editable). End effectors are visual only and add no mass: set the tool + workpiece mass in TCP Payload, as in UFACTORY Studio.

### Default TCP offsets [x, y, z mm, r, p, y °]
| End effector | Arms | Default TCP | Source |
|---|---|---|---|
| None | all | [0, 0, 0, 0, 0, 0] | flange |
| Gripper G2 | UF850, xArm5/6/7 | [0, 0, 172, 0, 0, 0] | ufactory_genesis URDF tcp joint |
| BIO Gripper G2 | UF850, xArm5/6/7 | [159.5, 0, 59.5, 0, 0, 0] | official UFACTORY value |
| Lite6 gripper | Lite6 | [0, 0, 83.6, 0, 0, 0] | ufactory_genesis URDF tcp joint |
| Lite6 vacuum gripper | Lite6 | [0, 0, 61.1, 0, 0, 0] | official UFACTORY value |

The 0.1.0 "Gripper G2" preset of 101.1 mm was a grasp-planning offset, not the TCP; it is dropped from projects on load.

## Official maximum joint torques
ufactory_genesis is now pinned to commit `be49519`, which carries the official UFACTORY maximum joint torques ([UFACTORY joint parameters](https://docs.supportarticle.ufactory.cc/zhHans/support_articles/hardware/ufactory-joint-parameters.html)). Utilization percentages change; absolute torques are unchanged. Example (UF850 golden case, 3 kg payload): J2 74.958 N·m = 19.6 % (was 37.5 %), J3 -30.634 N·m = 12.6 % (was 34.0 %).

- "Rated" is renamed to **"% of max torque"** (中文：占最大扭矩 %) in the UI.
- CSV export column `rated_nm` is renamed to **`max_torque_nm`**.

## Supported models
UF850, xArm5 / xArm6 / xArm7 (`_1305` revision only), Lite6.

## Platform and install
Linux x86_64, deb only (tested on Ubuntu 22.04+). Verify with `sha256sum -c SHA256SUMS.txt`. The package is **unsigned**.

## Known issues
- The installer is large (~100 MB) because the bundled Pinocchio engine pulls in extra libraries (coal, assimp, OpenBLAS).
- Windows is not packaged yet (planned for milestone M5); macOS is not supported.
- The package is not signed.
- Results are static models: nominal URDF inertia, no friction, gearbox efficiency or per-unit calibration.
