UGClient (UFACTORY Genesis Client) is a desktop client for kinematics, dynamics and 3D visualization of UFACTORY arms, built on [ufactory_genesis](https://github.com/xArm-Developer/ufactory_genesis) and Pinocchio.

## New: motion control bar (simulation only)
A collapsible control bar under the 3D view jogs the **simulated** arm. It does not connect to a real robot or the xArm SDK.

- **Joints:** J1-J6 sliders with joint limits, a value box and -/+ buttons.
- **TCP (base frame):** Z-/Z+ and Yaw-/Yaw+ buttons, plus round XYZ (X+/X-/Y+/Y-) and RPY (P+/P-/R+/R-) jog pads.
- **Click** moves one step: 1 mm for linear axes, 1° for rotation and joints. **Press and hold** (more than 300 ms) moves continuously until you release.
- **Speed** slider, default 50 %. 100 % is 230 mm/s linear and 40 °/s for joints and rotation.
- **Home** moves all joints to 0. **Align** turns only the last three joints so the tool points straight down (roll 180°, pitch 0°, current heading). The TCP position may change. If that pose can't be reached, an error is shown.
- **STOP**, or releasing a held button, stops motion and sets the simulated state to 4. The state panel shows 2 = ready, 1 = moving, 4 = stopped.
- Reaching a joint limit or an unreachable TCP target stops motion and shows a message.

New engine API methods: `motion.jog_tcp` and `motion.align`.

## New look
The app now follows the UFACTORY Studio-style design. A light 3D scene fills the window, and dark floating panels sit on top of it:
- **Left:** robot model, end effector, TCP offset, payload, connection status, language switch
- **Right:** read-only state (state, mode, payload, mounting, TCP pose, joint angles)
- **Bottom:** motion bar
- **Top:** view toolbar (reset view, Base/TCP/COM)

## Removed from the UI (temporarily)
- **The joint torque table and CSV export have no UI in this version.** Torque is still computed, and the engine API is unchanged (`dyn.gravity`, `check.pose`, `dyn.rnea`, `dyn.mass_matrix`). A torque view will return in a later release.
- The "Target TCP pose / Solve IK" form, the IK solution picker and the flange pose readout. `kin.ik` and `check.pose` remain in the API.
- The Check / Trajectory / Workspace tabs. Trajectory and Workspace were placeholders.

## Install / upgrade
```bash
sudo apt install ./ugclient_0.2.0_amd64.deb
ugclient
```

## Supported models
UF850, xArm5 / xArm6 / xArm7 (`_1305` revision only), Lite6.

## Platform and install
Linux x86_64, deb only (tested on Ubuntu 22.04+). Verify with `sha256sum -c SHA256SUMS.txt`. The package is **unsigned**.

## Known issues
- Jogging is simulation only. Single steps and speeds are fixed constants until a settings page exists.
- The installer is large (~100 MB) because the bundled Pinocchio engine pulls in extra libraries (coal, assimp, OpenBLAS).
- Windows is not packaged yet; macOS is not supported.
- The package is not signed.
- Results are static models: nominal URDF inertia, no friction, gearbox efficiency or per-unit calibration.
